# aggchain-multisig contracts

All the files and directories within this directory have been generated using the import-contracts command of the CLI in this repo.
The ABI and the binnaries of the smart contracts have been extracted from [agglayer-contracts repo](https://github.com/agglayer/agglayer-contracts.git), using the version v13.0.0-rc.0 (commit 4839628561712c7477366e79d0a280a0a546b8fe)

The CLI command used to generate the contracts: `$ go run ./cmd import-contracts -cv v13.0.0-rc.0 -alias aggchain-multisig -node 24 -replace`
