# aggchain-multisig contracts

All the files and directories within this directory have been generated using the import-contracts command of the CLI in this repo.
The ABI and the binnaries of the smart contracts have been extracted from [agglayer-contracts repo](https://github.com/agglayer/agglayer-contracts.git), using the version a6b96a86f8ec6345b2fa2f618f3f8c418c6c6d92 (commit a6b96a86f8ec6345b2fa2f618f3f8c418c6c6d92)

The CLI command used to generate the contracts: `$ go run ./cmd import-contracts -cv a6b96a86f8ec6345b2fa2f618f3f8c418c6c6d92 -alias aggchain-multisig -node 24`
